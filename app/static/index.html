YOUR FIRST CONNECTION

Set up your monitoring

Create groups for basic checks, IoT devices, or networks you can already reach. Add as many devices as you need; checks run in small batches.

Find each device’s address in its network settings or your router’s connected-device list. Ping works for most devices. Choose TCP only for a port you know accepts connections.

Internet path checks are optional for each group. Your existing LAN/VPN routes provide connectivity; this app does not set up networking. Removing a device or group stops its checks after saving; stored history is retained.
